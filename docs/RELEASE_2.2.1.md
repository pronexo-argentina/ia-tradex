# IA-TradeX 2.2.1

IA-TradeX 2.2.1 es una release visual.

La aplicación adopta una paleta violeta oscuro en fondos, paneles, selectores, tablas, botones, gráficos y estados de selección.

Los colores semánticos de éxito, advertencia y error se conservan para no perder claridad operativa.

No se modifica ninguna lógica funcional respecto de v2.2.0.
