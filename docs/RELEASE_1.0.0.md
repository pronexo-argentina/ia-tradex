# IA-TradeX 1.0.0

Primera versión estable de la base funcional de IA-TradeX.

Incluye análisis técnico y backtesting, mercados Crypto/Argentina/Internacional, Scanner y watchlists, Paper Trading manual y automático, Cartera AUTO multi-activo, gestión de riesgo y exposición, Performance y exportación CSV.

La versión 1.0.0 continúa siendo una plataforma de análisis y simulación. No envía órdenes reales.

Las siguientes etapas se concentran en validación más rigurosa, datos más frecuentes y Machine Learning después de contar con suficiente evidencia histórica y de Paper Trading.
